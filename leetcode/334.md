### Question
Given an integer array `nums`, return `true` _if there exists a triple of indices_ `(i, j, k)` _such that_ `i < j < k` _and_ `nums[i] < nums[j] < nums[k]`. If no such indices exists, return `false`.

**Example 1:**
**Input:** nums = [1,2,3,4,5]
**Output:** true
**Explanation:** Any triplet where i < j < k is valid.

**Example 2:**
**Input:** nums = [5,4,3,2,1]
**Output:** false
**Explanation:** No triplet exists.

**Example 3:**
**Input:** nums = [2,1,5,0,4,6]
**Output:** true
**Explanation:** The triplet (3, 4, 5) is valid because nums[3] == 0 < nums[4] == 4 < nums[5] == 6.

**Constraints:**
- `1 <= nums.length <= 5 * 105`
- `-231 <= nums[i] <= 231 - 1`

### My Solution
주어진 무작위 수열 `nums`에서 Index $(i, j, k)$가 $i < j < k$와 `nums[i] < nums[j] < nums[k]`를 모두 만족하는 `i, j, k`가 있는지 여부를 판단하는 문제.
반드시 세 인덱스가 인접해야 할 필요는 없기 때문에, 조건을 만족하는 각 `nums[i], nums[j], nums[k]`에 해당할 수 있는 숫자들이 존재하는지를 찾고자 하였다.

해답을 작성한 사람 중 좋은 설명이 되는 그림이 있어서 참조하였다. 
우선, `nums[i], nums[j]`에 해당하는 값을 초기화 해주고, `nums`안에 있는 각 숫자 `num`에 대해서 순회하며 다음과 같은 비교를 진행한다.
1. `num <= nums[i] ?`: 만약 `num`이 작거나 같다면 `nums[i]`를 `num`으로 지정해준다.
2. `num <= nums[j] ?`: 만약 `num`이 작거나 같다면 `nums[j]`를 `num`으로 지정해준다.
3. 두 조건문을 통과하면, `nums[i], nums[j]`보다 큰 수 이므로, Triplet이 존재함을 알 수 있다.

#### **"왜 first가 나중에 업데이트되어도 괜찮을까?" by Claude**
`first`가 나중에 업데이트되어도, 이전의 `second` 값은 여전히 유효합니다. 왜냐하면:

- `second`가 설정될 당시에는 분명히 어떤 값보다 큰 상태였기 때문
- 새로운 `num`이 `second`보다 크다면, 과거의 (first, second, num) 조합이 여전히 증가하는 triplet을 형성

이 알고리즘은 **greedy approach**의 좋은 예시로, 각 단계에서 가능한 한 작은 값들을 유지함으로써 미래에 triplet을 찾을 확률을 최대화합니다.

정말 효율적이고 우아한 해결책이네요! 👍

### Code
```python
class Solution(object):
    def increasingTriplet(self, nums):
        """
        :type nums: List[int]
        :rtype: bool
        """
        first = float('inf')
        second = float('inf')
	    
        for num in nums:
            if num <= first:
                first = num
            elif num <= second:
                second = num
            else:
                return True
        return False
```
