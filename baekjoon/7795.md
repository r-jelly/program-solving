### Question
**문제**
심해에는 두 종류의 생명체 A와 B가 존재한다. A는 B를 먹는다. A는 자기보다 크기가 작은 먹이만 먹을 수 있다. 예를 들어, A의 크기가 {8, 1, 7, 3, 1}이고, B의 크기가 {3, 6, 1}인 경우에 A가 B를 먹을 수 있는 쌍의 개수는 7가지가 있다. 8-3, 8-6, 8-1, 7-3, 7-6, 7-1, 3-1.

두 생명체 A와 B의 크기가 주어졌을 때, A의 크기가 B보다 큰 쌍이 몇 개나 있는지 구하는 프로그램을 작성하시오.

**입력**
첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스의 첫째 줄에는 A의 수 N과 B의 수 M이 주어진다. 둘째 줄에는 A의 크기가 모두 주어지며, 셋째 줄에는 B의 크기가 모두 주어진다. 크기는 양의 정수이다. (1 ≤ N, M ≤ 20,000) 

**출력**
각 테스트 케이스마다, A가 B보다 큰 쌍의 개수를 출력한다.

### Solution
A의 특정 숫자에 대해, B에 해당 숫자보다 작은 숫자가 몇 개가 있는지를 전부 세는 문제이다.
Brute force를 사용해도 해결은 할 수 있지만, 시간복잡도 측면에서 문제가 생긴다. $O(MN)$

Two pointer 방식을 이용하면, $O(MlogM+NlogN)$의 복잡도로 해결할 수 있다.
- 우선 입력받은 A, B를 내림차순으로 정렬한다.
- A의 임의의 숫자 `A[a]`에 대해, B의 임의의 숫자 `B[b]`보다 작다면, 인덱스를 `b+1`로 변경한다.
- 만약 `A[a] > B[y]`라면, B에는 `A[a]`보다 작은 숫자가 `M-y`개 존재한다.
- 다음 숫자인 `A[a+1]`에 대해서는 `B[y]`부터 비교를 진행하면 된다.
	- Why? A, B는 내림차순 정렬이므로, `A[a]>=A[a+1]`이고, 따라서 `b<y`인 모든 `b`에 대해, `B[b]>=A[a]>=A[a+1]`이 성립한다.

### Code
```python
import sys

T = int(sys.stdin.readline())
for _ in range(T):
    N, M = list(map(int, sys.stdin.readline().split()))
    nums_a = list(map(int, sys.stdin.readline().split()))
    nums_b = list(map(int, sys.stdin.readline().split()))
	
    nums_a.sort(reverse=True)
    nums_b.sort(reverse=True)
	
    answer, idx_b = 0, 0
    for idx_a in range(N):
        while idx_b<M:
            if nums_a[idx_a] <= nums_b[idx_b]:
                idx_b += 1
            else:
                break
        answer += M-idx_b
    print(answer)
```
