### Question
**문제**
어떤 정수 A가 있으면 그 수를 A = a1 * a2 * a3 * a4 ... * an으로 했을 때 A' = a1 + a2 + a3 ... + an이 성립하면 "A는 A'으로 변할 수 있다"라고 한다. (ai는 정수) 만약 A'이 A"으로 변할 수 있으면 "A는 A"으로 변할 수 있다"라고 한다.

이때 A와 B가 주어지면 A는 B로 변할 수 있는지 판별하시오.

**입력**
첫째 줄에는 테스트 케이스의 개수 T(1 ≤ T ≤ 100)이 주어진다. 테스트 케이스마다 두 정수 A, B(-231 ≤ A, B ≤ 231-1)가 주어진다.

**출력**
각각의 테스트 케이스마다 한 줄에 변할 수 있으면 yes, 아니면 no를 출력한다.

### Solution
얼핏 보았을 때, 소인수분해를 통한 경우의 수를 모두 찾아야하는 문제처럼 보였다.
그러나 문제의 정의를 살펴보았을 때, $A=a_1 \times a_2 \times … \times a_n$일때, $A'=a_1+a_2+…+a_n$이 성립하면 `A는 A'로 변할 수 있다.`라고 할 수 있기 때문에, 크게 세 가지 경우를 생각할 수 있다.
1. $A=A \times 1$ 인 경우: 이때는 $A'=A+1$이 성립하기 때문에, $A$는 자기 자신보다 큰 모든 정수에 대해 변할 수 있음이 성립한다.
2. $A=A \times 1 \times (-1) \times (-1)$인 경우: 이때는 $A'=A+1+(-1)+(-1)=A-1$이 성립하기 때문에, $A$는 자기 자신보다 작은 모든 정수에 대해 변할 수 있음이 성립한다.
3. $A=A$인 경우: 이때는 $A'=A$이므로, 자기 자신에 대해서도 변할 수 있다.
따라서, **어떠한 $A$의 경우에도 모든 정수로 변할 수 있음**이 성립하게 된다.

### Code
```python
T = int(input())
for _ in range(T):
    A, B = list(map(int, input().split()))
    print("yes")
```
