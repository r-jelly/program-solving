### Question
**문제**
음 아닌 정수 N이 주어졌을 때, 이 수를 서로 다른 정수 M(M ≥ 1)개의 팩토리얼의 합으로 나타낼 수 있는지 알아내는 프로그램을 작성하시오. 예를 들어 2=0!+1!로 나타낼 수 있지만, 5는 이와 같은 방식으로 나타낼 수 없다.

**입력**
첫째 줄에 정수 N이 주어진다.

**출력**
입력으로 주어진 수를 서로 다른 정수 M개의 팩토리얼의 합으로 나타낼 수 있으면 YES, 없으면 NO를 출력한다. 

**제한**
- 0 ≤ N ≤ 1,000,000,000,000,000,000

### Solution
정수 N을 서로 다른 정수의 팩토리얼 합으로 나타낼 수 있는지를 구하는 문제.
우선 제한조건이 20!을 넘지 않으므로, 0!-20!까지의 값을 미리 구해놓았다.

Greedy한 방법론을 이용하여, 제일 큰 팩토리얼 값부터 차례로 해당 정수에서 뺄 수 있는지를 확인해 뺄 수 없을 때 까지 N에서 뺄셈 해줍니다.
이때, 남은 숫자가 0이 아니게 되면, 서로 다른 팩토리얼 조합으로 구할 수 없는 숫자이므로 NO를 출력하고, 0이라면 YES를 출력합니다.

#### 왜 그리디 알고리즘으로 해결 할 수 있나?
예를 들어, [2, 249, 250]의 조합에서 251을 만들 수 있냐고 한다면, 제일 큰 수부터 빼는 것은 정답이 아닐 것이다.
Why? $250 < (249 + 2)$이므로 다른 조합이 더 최적인 경우가 발생

팩토리얼은 n! > [(n-1)! + (n-2)! + … + 1! + 0!]을 만족한다.
따라서, 아래 증명을 이용해서 제일 큰 팩토리얼부터 빼는 것이 최선임을 증명할 수 있다.

> **핵심 아이디어**: 어떤 수 N을 서로 다른 팩토리얼들의 합으로 나타낼 수 있다면, 가장 큰 팩토리얼부터 빼는 것이 항상 최적이다.
> 
> **증명**: N을 서로 다른 팩토리얼들의 합으로 나타낼 수 있다고 가정합시다: $N = a_1! + a_2! + \cdots + a_k!$ (여기서 $a_1 > a_2 > \cdots > a_k \geq 0$)
> 
> 만약 $a_1 < m$ (여기서 $m!$은 N보다 작거나 같은 가장 큰 팩토리얼)이라면: $N = a_1! + a_2! + \cdots + a_k! < m! + (m-1)! + \cdots + 0! < m!$
> 
> 이는 $m!$의 정의에 모순됩니다. 따라서 반드시 $a_1 = m$이어야 합니다.

### Code
```python
import sys
input = sys.stdin.readline

def solution(N):
    if N==0:
        return "NO"
    
    facts = [1, 1]
    for i in range(2, 20):
        facts.append(facts[i-1] * i)

    for i in reversed(range(20)):
        if N >= facts[i]:
            N -= facts[i]

    if N==0:
        return "YES"
    else:
        return "NO"
    

if __name__ == "__main__":
    N = int(input())
    print(solution(N))
```
