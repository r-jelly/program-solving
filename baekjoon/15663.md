### Question
**문제**
N개의 자연수와 자연수 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성하시오.

- N개의 자연수 중에서 M개를 고른 수열

**입력**
첫째 줄에 N과 M이 주어진다. (1 ≤ M ≤ N ≤ 8)

둘째 줄에 N개의 수가 주어진다. 입력으로 주어지는 수는 10,000보다 작거나 같은 자연수이다.

**출력**
한 줄에 하나씩 문제의 조건을 만족하는 수열을 출력한다. 중복되는 수열을 여러 번 출력하면 안되며, 각 수열은 공백으로 구분해서 출력해야 한다.

수열은 사전 순으로 증가하는 순서로 출력해야 한다.

### Code
```python
import sys

N, M = list(map(int, sys.stdin.readline().split()))
nums = list(map(int, sys.stdin.readline().split()))

visited = [False]*N
seq     = set()
stack   = list()

nums.sort()

def dfs(cur_seq, length=0):
    if length == M:
        if '-'.join(cur_seq) not in seq:
            seq.add('-'.join(cur_seq))
            for i in cur_seq:
                sys.stdout.write(str(i)+" ")
            sys.stdout.write("\n")
        return
    
    for i in range(N):
        if visited[i]:
            continue

        visited[i] = True
        cur_seq.append(str(nums[i]))
        dfs(cur_seq[:], length+1)
        visited[i] = False
        cur_seq.pop()

dfs(stack, 0)
```

### My Answer
[[BOJ 15654 - N과 M (5)]] 문제에서 입력으로 주어지는 수의 중복을 허용한 문제.
이전 문제와 마찬가지로 DFS와 Backtracking 기법을 이용해서 문제를 해결하였다.

여기서 중요한 점은, **중복되는 수열을 여러 번 출력하면 안된다**는 것!
즉, `1, 1, 2, 3`으로 두 자리 수의 수열을 만들 때, `2, 1`은 2번이 아니라 1번 출력되어야 한다.
이를 해결하기 위해서 나는 `length(=M)` 만큼 수열을 만들고, 수열을 하나로 이어붙인 `string`을 `set` 자료형에 넣어서 중복 여부를 판단하였다.
즉, 하나의 수열을 만들었을 때, `"2-1"`이라는 `string`을 `set`에 넣는다!

> 왜 `-`를 붙이나요? 안붙이고 그냥 수열을 `"".join(seq)` 한다면 `2, 22`, `22, 2`와 같은 케이스를 서로 같은 수열이라고 판단하게 된다.

> `A in list`: $O(N)$의 시간복잡도 → 순차적으로 돌면서 확인해야 하므로
> `A in set(or dict)`: $O(1)$의 시간복잡도 (최악의 경우에만 $O(N)$) → Hash Function을 이용해서 탐색하므로 훨씬 시간복잡도가 적음!

#### Good Answer
Tree 탐색 중 똑같은 숫자를 특정 node의 다음 node로 중복해서 이용하지 않도록, 해당 시점에서 사용한 다음 node의 숫자를 저장하는 변수를 만든다.
즉, `[1, 2, 2, 3, 3, 4]` 라는 숫자들 중에서 세 자리 수의 수열을 만들 때, 각 숫자는 `[1, 2(0), 2(1), 3(0), 3(1), 4]`라고 생각할 수 있다. 따라서, `1->2(0)`과 `1->2(1)`은 결과적으로 똑같은 수열을 생성하므로, 이를 건너뛴다면 훨씬 효율적으로 문제를 해결할 수 있다.

```python
def dfs(cur_seq, length=0):
    if length == M:
        for i in cur_seq:
            sys.stdout.write(str(i)+" ")
        sys.stdout.write("\n")
        return

	overlap = -1
    for i in range(N):
        if visited[i] or nums[i]==overlap:
            continue

        visited[i] = True
        cur_seq.append(str(nums[i]))
        overlap = nums[i] # 이전에 탐색했던 숫자 기억!
        
        dfs(cur_seq[:], length+1)
        visited[i] = False
        cur_seq.pop()
```
