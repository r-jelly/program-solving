### Question
**문제**
자연수 N과 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성하시오.

- 1부터 N까지 자연수 중에서 M개를 고른 수열
- 같은 수를 여러 번 골라도 된다.
- 고른 수열은 비내림차순이어야 한다.
    - 길이가 K인 수열 A가 A1 ≤ A2 ≤ ... ≤ AK-1 ≤ AK를 만족하면, 비내림차순이라고 한다.

**입력**
첫째 줄에 자연수 N과 M이 주어진다. (1 ≤ M ≤ N ≤ 8)

**출력**
한 줄에 하나씩 문제의 조건을 만족하는 수열을 출력한다. 중복되는 수열을 여러 번 출력하면 안되며, 각 수열은 공백으로 구분해서 출력해야 한다.

수열은 사전 순으로 증가하는 순서로 출력해야 한다.

### Solution
기초적인 Backtracking 문제. [[BOJ 15654 - N과 M (5)]]와는 다르게 수열이 반드시 비내림차순이어야 하며, 숫자들의 중복을 허용하였다.

주어진 숫자가 `1, 2, ..., N`까지고, 비내림차순이라는 조건이 있으므로 따로 `Visited` 배열을 만들 필요 없이 범위를 좁혀나갈 수 있다.
특정 숫자 `i`가 수열의 한 숫자라고 할 때, 다음 순서는 항상 `i, i+1, ..., N` 중 하나의 숫자가 되어야만 한다. 따라서, 단순히 시작 숫자 `i`에 대해 반복문을 `i~N`까지 반복하며 Recursion을 진행하면 된다! (종료 조건은 수열의 길이가 `M`이 되는 순간)

### Code
```python
N, M = list(map(int, input().split()))

def dfs(node: int, seq: list, length: int):
    if length == M:
        print(*seq)
        return
    
    for i in range(node, N+1):
        seq.append(i)
        dfs(i, seq, length+1)
        seq.pop()
    return

dfs(1, [], 0)
```
