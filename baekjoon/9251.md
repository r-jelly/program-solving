### Question
**문제**
LCS(Longest Common Subsequence, 최장 공통 부분 수열)문제는 두 수열이 주어졌을 때, 모두의 부분 수열이 되는 수열 중 가장 긴 것을 찾는 문제이다.

예를 들어, ACAYKP와 CAPCAK의 LCS는 ACAK가 된다.

**입력**
첫째 줄과 둘째 줄에 두 문자열이 주어진다. 문자열은 알파벳 대문자로만 이루어져 있으며, 최대 1000글자로 이루어져 있다.

**출력**
첫째 줄에 입력으로 주어진 두 문자열의 LCS의 길이를 출력한다.

### My Answer
처음 아이디어는 문자열 1개를 고정하고, 다른 1개의 문자열 길이를 늘려가면서 부분 수열의 최댓값을 찾는 것이었다. 즉, Greedy하게 부분 수열의 시작점을 잡고 계속 시작점을 업데이트하면서 수열을 찾는 것이다. 이 방법의 문제는 어떤 시작점이 최선의 상태인지를 업데이트 하는 과정 속에서 알기 어렵다는 것이었다.

따라서 [[Dynamic Programming]]을 이용한 해결법을 생각하게 되었다.
두 문자열의 Index를 각각 행, 열로 두는 2차원 배열 `dp[][]`를 생각했을 때, `dp[i][j]`는 문자열 `A`의 `0~i`까지의 부분문자열과 `B`의 `0~j`까지의 부분문자열끼리의 LCS 값이다. 이때 두 가지 경우로 나눠서 해결할 수 있다.
1. `A[i]==B[j]`: `A[i-1], B[j-1]`에서의 LCS에서 `A[i]==B[j]` 문자를 추가하는 것이므로, `dp[i-1][j-1]`에 `1`을 더한 값을 `dp[i][j]`에 저장한다.
2. `A[i]!=B[j]`: 해당 위치의 두 문자는 동시에 LCS에 포함될 수 없으므로, 둘 중 한 가지 문자는 아예 고려하지 않아도 된다. 따라서, `dp[i][j-1], dp[i-1][j]` 중 최댓값을 `dp[i][j]`의 값으로 사용하면 된다.

**TIP!** 실제 구현시, DP table에 빈 문자열을 고려하도록 맨 앞에 1개의 행, 열을 추가해서 구현하면 쉽게 구현할 수 있다.

### Code
```python
A = input()
B = input()

dp = [[0]*(len(B)+1) for _ in range(len(A)+1)]
for i in range(len(A)):
	for j in range(len(B)):
		if A[i]==B[j]:
			dp[i+1][j+1] = dp[i][j]+1
		else:
			dp[i+1][j+1] = max(dp[i+1][j], dp[i][j+1])

print(dp[-1][-1])
```
