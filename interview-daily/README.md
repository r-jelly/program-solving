# LeetCode — 유지 모드 (방어선)

**목적:** 알고리즘 감각 유지 + 커밋 하한선 방어. 실력 향상보다 *설명 훈련*이 핵심.

**규칙**
- 하루 1문제(점심 12:00–13:00), medium 위주. hard 그라인딩은 하지 않는다.
- 코드만 커밋하지 않는다. 반드시 **STAR writeup**을 같이 남긴다 → 이게 없으면 커밋으로 인정하지 않는다.

**파일 규칙**
- `YYYYMMDD-<problem-slug>.md` 한 파일에 풀이 + STAR writeup.
- STAR 구조: 문제가 뭔가 / 왜 까다로웠나(핵심 관찰) / 접근과 대안 / 최종 선택과 복잡도 / 한계·엣지케이스.
- correctness 근거와 시간·공간 복잡도를 반드시 명시한다.

**과거 이력**
- 이 트랙 이전에 푼 문제(백준/프로그래머스/LeetCode, 코드만·STAR 없음)는 [`program-solving`](https://github.com/r-jelly/program-solving) 레포에 그대로 둔다. 마이그레이션하지 않음 — 여기서는 STAR writeup이 붙은 문제만 기록한다.
