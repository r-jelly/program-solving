### Question
**문제**
자연수 A를 B번 곱한 수를 알고 싶다. 단 구하려는 수가 매우 커질 수 있으므로 이를 C로 나눈 나머지를 구하는 프로그램을 작성하시오.

**입력**
첫째 줄에 A, B, C가 빈 칸을 사이에 두고 순서대로 주어진다. A, B, C는 모두 2,147,483,647 이하의 자연수이다.

**출력**
첫째 줄에 A를 B번 곱한 수를 C로 나눈 나머지를 출력한다.

### My Answer
쉽게 얘기해서, $A^B \mod C$의 값을 구하는 문제. 제한 시간이 `0.5`초로 매우 빠듯하였다. A, B, C가 각각 매우 큰 수가 들어올 수 있으므로, [[BOJ 1629 - 곱셈#모듈러의 분배법칙|모듈러의 분배법칙]]과 분할 정복을 이용하여 계산에 들어가는 비용을 줄여주었다.

예를 들어서, `A=7, B=37`인 경우를 생각하자, 단순히 A^B를 계산하고자 하면, 37번의 곱셈 연산을 필요로 한다. 그러나 $x^{2k} = x^k \times x^k$라는 것을 이용하면,
$7^{37} = 7 \times 7^{18} \times 7^{18}$
$7^{18} = 7^9 \times 7^9$
$7^9 = 7 \times 7^4 \times 7^4$
$7^4 = 7^2 \times 7^2$
즉, 7번의 곱셈 연산으로 감소시킬 수 있다.

#### 모듈러의 분배법칙
모듈러 연산에 대해서 다음과 같은 법칙이 적용된다.
$(A + B) \mod C = (A \mod C + B \mod C) \mod C$
$(A - B) \mod C = (A \mod C - B \mod C) \mod C$
$(A \times B) \mod C = (A \mod C \times B \mod C) \mod C$
$(A \div B) \mod C = (A \mod C \div B \mod C) \mod C$

### Code
```python
A, B, C = list(map(int, input().split()))

def new_pow(x, y, z):
    if y==1:
        return x%z
    elif y==2:
        return (x*x)%z

    x_part = new_pow(x, y>>1, z)

    if y%2:
        return (x%z * x_part * x_part) % z
    else:
        return (x_part * x_part) % z


print(new_pow(A, B, C))
```
