### Question
**문제**
N×M의 행렬로 표현되는 맵이 있다. 맵에서 0은 이동할 수 있는 곳을 나타내고, 1은 이동할 수 없는 벽이 있는 곳을 나타낸다. 당신은 (1, 1)에서 (N, M)의 위치까지 이동하려 하는데, 이때 최단 경로로 이동하려 한다. 최단경로는 맵에서 가장 적은 개수의 칸을 지나는 경로를 말하는데, 이때 시작하는 칸과 끝나는 칸도 포함해서 센다.

만약에 이동하는 도중에 한 개의 벽을 부수고 이동하는 것이 좀 더 경로가 짧아진다면, 벽을 한 개 까지 부수고 이동하여도 된다.

한 칸에서 이동할 수 있는 칸은 상하좌우로 인접한 칸이다.

맵이 주어졌을 때, 최단 경로를 구해 내는 프로그램을 작성하시오.

**입력**
첫째 줄에 N(1 ≤ N ≤ 1,000), M(1 ≤ M ≤ 1,000)이 주어진다. 다음 N개의 줄에 M개의 숫자로 맵이 주어진다. (1, 1)과 (N, M)은 항상 0이라고 가정하자.

**출력**
첫째 줄에 최단 거리를 출력한다. 불가능할 때는 -1을 출력한다.

### My Answer
미로 탐색 문제와 유사하지만 하나 다른 점은 벽을 1번 뚫을 수 있다는 점.
최단 거리를 탐색해야 하기 때문에 DFS가 아니라 반드시 BFS로만 해결해야 한다.
#### Why?
DFS로 경로를 찾으면 결국 모든 경로에 대해서 거리를 구해 그 중 최소 거리를 찾아야 하는데, 이는 시간적으로 매우 손해.
#### Idea 1
처음에는 단순히 기존 BFS와 동일하게 구현하되, 벽을 뚫었는지 여부를 저장하는 변수 1개를 추가로 이용하였다. 즉, 만약 벽(`1`)을 마주했을 때,
1. 이미 벽을 뚫었다면, 다음 벽을 뚫을 수 없다.
2. 한 번도 벽을 뚫지 않았다면, 다음 벽을 뚫어 경로로 이용할 수 있다.
이런 알고리즘으로 구현하였다. 

**문제점)** 아래와 같은 반례가 발생하였다.
```
3 6
011001
000110
100100

정답: 8
오답: -1
```

위와 같은 상황에서 `(row, col) = (2, 2)` 지점을 생각해보자. 해당 지점에 도달하는 경우는 크게 2가지로 나눌 수 있을 것이다.
1. 벽을 뚫어서 온 경우: `(0,0)-(1,0)-(2,0)-(2,1)-(2,2)`
2. 벽을 뚫지 않은 경우: `(0,0)-(1,0)-(1,1)-(1,2)-(2,2)` 
문제는, 최종 지점인 `(2, 5)`에 도달하려면 반드시 `(2, 3)`에 있는 벽을 뚫어야 한다는 것이다. 이때, 벽을 뚫어서 온 1번의 경로가 먼저 탐색된다면, 2번의 경로는 `(2, 2)`에 도달하지 못하므로 결국 최종 지점에 도달할 수 없다.

즉, 특정 지점까지 벽을 부수고 온 것이 벽을 부수지 않고 온 것에 비해 최적이라고 가정해보자. 만약 현재 지점에서 목적 지점까지 반드시 벽을 부숴야 한다면, 벽을 부수고 온 것이 현재까지 최적이더라도 해당 경로가 아니라 더 먼 경로라도 현재 지점까지 벽을 부수지 않고 온 경로를 선택해야 한다는 것이다.

따라서, 현재까지 벽을 한 번도 부수지 않았을 때와 부쉈을 때, 2가지 경우의 방문 기록을 따로 저장해서 해결해야 한다.

#### Idea 2
위 아이디어에 따라 `visited` 배열을 아래와 같이 2개 만들어 주었다.
1. 한 번도 벽을 부수지 않는 경로의 각 지점 방문 여부를 저장하는 배열
2. 벽을 한 번 부순 경로의 각 지점 방문 여부를 저장하는 배열

벽을 부수지 않았을 때는, 1번 배열에 방문 기록을 저장한다. 그러다 벽을 만난 이후부터는 2번 배열에 방문 기록을 저장하면 된다. 이렇게 한다면 아까와 같은 반례 상황을 해결할 수 있다.

### Code
```python
import sys
from collections import deque

N, M = list(map(int, sys.stdin.readline().split()))
board = []
for _ in range(N):
    line = list(map(int, list(sys.stdin.readline().strip())))
    board.append(line)

move = [(1, 0), (0, 1), (-1, 0), (0, -1)]
visited = [[False]*M for _ in range(N)]
visited_wall = [[False]*M for _ in range(N)]

visited[0][0] = True
queue = deque([(0, 0, 1, True)])
final_depth = -1

while queue:
    row, col, cur_depth, can_break = queue.popleft()
    if row==N-1 and col==M-1:
        final_depth = cur_depth
        break

    for dx, dy in move:
        if not ( (0<=row+dx<N) and (0<=col+dy<M) ):
            continue

        if can_break and visited[row+dx][col+dy]:
            continue
        elif not can_break and visited_wall[row+dx][col+dy]:
            continue

        if board[row+dx][col+dy] == 1:
            if not can_break:
                continue
            else:
                next_break = False
        else:
            next_break = can_break

        if next_break:
            visited[row+dx][col+dy] = True
        else:
            visited_wall[row+dx][col+dy] = True
        queue.append((row+dx, col+dy, cur_depth+1, next_break))

print(final_depth)
```
- `visited`, `visited_wall` 배열을 각각 만들어 벽을 부수지 않은 경우와 한 번 벽을 부순 경우의 방문 기록을 저장하였다.
- Queue에 `(현재 위치, 현재까지의 거리, 벽을 부쉈는지 여부)`를 전달하여 최단 거리 탐색과 벽을 지나갈 수 있는지 여부를 판단하게 하였다.

결과적으로 N개의 상태가 존재한다고 했을 때, 각 상태에 따라 다른 배열을 적용해야 한다!
