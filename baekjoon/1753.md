### Question
[Link](https://www.acmicpc.net/problem/1753)

**문제**
방향그래프가 주어지면 주어진 시작점에서 다른 모든 정점으로의 최단 경로를 구하는 프로그램을 작성하시오. 단, 모든 간선의 가중치는 10 이하의 자연수이다.

**입력**
첫째 줄에 정점의 개수 V와 간선의 개수 E가 주어진다. (1 ≤ V ≤ 20,000, 1 ≤ E ≤ 300,000) 모든 정점에는 1부터 V까지 번호가 매겨져 있다고 가정한다. 둘째 줄에는 시작 정점의 번호 K(1 ≤ K ≤ V)가 주어진다. 셋째 줄부터 E개의 줄에 걸쳐 각 간선을 나타내는 세 개의 정수 (u, v, w)가 순서대로 주어진다. 이는 u에서 v로 가는 가중치 w인 간선이 존재한다는 뜻이다. u와 v는 서로 다르며 w는 10 이하의 자연수이다. 서로 다른 두 정점 사이에 여러 개의 간선이 존재할 수도 있음에 유의한다.

**출력**
첫째 줄부터 V개의 줄에 걸쳐, i번째 줄에 i번 정점으로의 최단 경로의 경로값을 출력한다. 시작점 자신은 0으로 출력하고, 경로가 존재하지 않는 경우에는 INF를 출력하면 된다.

### My Answer
Graph의 한 점에서 다른 모든 점까지의 최단거리를 구하는 문제.
최종적으로는 Min Heap을 이용한 [[Dijkstra Algorithm|Dijkstra 알고리즘]]을 이용해서 해결했다.

제일 우선적으로, 특정 Node A에 연결되어 있는 모든 Node B에 대한 (Node, Weight)를 저장하는 2차원 배열을 구성한다.
#### 풀이 1
Queue를 이용해서 해결하였다. 시작 노드 K와의 최단 거리를 저장하는 배열인 `Dist[]`를 만든다.
1. 시작 노드 K와 최단 거리 0을 Queue에 넣는다. `(K, 0)`
2. Queue에서 Pop을 진행해 현재 노드 `A`와, K에서 A까지의 최단거리 `D`를 얻는다.
3. `A`와 연결된 모든 노드 `B`에 대해서, `A-B`간의 가중치를 `w`라고 하자.
4. 이때, `D+w`와 `Dist[B]`의 크기를 비교해서, `D+w`가 작으면 `Dist[B]=D+w`로 하고, Queue에 `(B, Dist[B])`를 넣는다.
5. 2~5의 과정을 Queue가 전부 빌때까지 반복한다.
*문제점!* Queue에 중복된 Node가 계속 들어올 가능성이 있음. → 만약, 계속해서 갱신이 된다고 하면 계속 Node를 Queue에 집어넣게 됨. 따라서 최악의 경우 $O(VE)$의 시간복잡도를 소비!

#### 풀이 2
풀이 1에서의 문제는, 현재 노드에서의 최소 거리를 찾아도 해당 거리가 항상 최소인지가 보장되지가 않았다. 이러한 문제를 해결하기 위해, 다음 탐색할 노드를 선택할 때 항상 탐색 후보에 있는 노드 중 K와의 거리가 최소인 노드를 다음 탐색 노드로 선택하였다.
즉, 음수 가중치가 없다면, 현재 최소 거리가 보장된 노드는 다시 방문하지 않을 것이다.
*e.g.)* `A -> [(B, 2), (C, 3), (D, 4)]`라고 한다면, `B`는 항상 `A`에서의 거리가 최소값이다. **Why?** `A->B` 보다 더 최소인 거리가 있다고 하면, `A->X->B`의 경로가 되어야 하는데, `A`에서 연결된 `B`가 아닌 다른 모든 노드는 `A->B`의 거리보다 크다. 따라서, `A->B`는 항상 최단 경로로 보장된다.

이런 방법으로 문제를 해결하기 위해서, Heap을 사용해 최선의 시간복잡도로 다음 후보 노드 중 최단 거리를 갖는 노드를 탐색했다. 즉, 풀이 1에서 2번째 줄을 최적화 한 것이다.
1. 시작 노드 K와 최단 거리 0을 Heap에 넣는다. `(0, K)`
2. Heap에서 거리가 제일 작은 노드를 Pop하여, K에서 A까지의 최단거리 `D`와 현재 노드 `A`를 얻는다. 이때, K에서 A까지의 최단거리 `D`는 최소값임이 보장된다.
3. `A`와 연결된 모든 노드 B에 대해서, `A-B`간의 가중치를 `w`라고 했을 때, `Dist[A]+w`와 `Dist[B]`를 비교한다. 즉 `K->A->B`와 `K->B`간의 거리 중 어디가 더 최단 경로인지를 비교한다.
4. `Dist[A]+w`가 더 작다면, `Dist[B]`를 갱신하고, Heap에 `(Dist[B], B)`를 넣는다.
5. 2~5의 과정을 Heap이 전부 빌 때까지 반복한다.
2에서 Greedy한 방법을 이용해 탐색할 Node를 하나씩 줄여가게 된다. 즉, 2에서 선택된 노드는 다시 방문하지 않는다. 최종적으로 $O(E \log V)$의 시간복잡도를 갖는다. → Dijkstra Algorithm
*추가적 최적화?* 방문한 노드를 저장해서 처리

### Code
#### 풀이 1
```python
from collections import deque

V, E = list(map(int, input().split()))
K = int(input())
graph = [[] for _ in range(V+1)]
for i in range(E):
    u, v, w = list(map(int, input().split()))
    graph[u].append((v, w))

weight = [float('inf')] * (V+1)
weight[K] = 0

queue = deque([(K, 0)])
while queue:
    cur_node, cur_w = queue.popleft()
	
    for n, w in graph[cur_node]:
        if cur_w+w < weight[n]:
            weight[n] = cur_w+w
            queue.append((n, weight[n]))

for i in range(1, V+1):
    if weight[i] == float("inf"):
        print("INF")
    else:
        print(weight[i])
```

import heapq

V, E = list(map(int, input().split()))
K = int(input())
graph = [[] for _ in range(V+1)]
for i in range(E):
    u, v, w = list(map(int, input().split()))
    graph[u].append((v, w))

distance = [float('inf')] * (V+1)
distance[K] = 0
visited = [False] * (V+1)

queue = [(0, K)]
while queue:
    cur_d, cur_node = heapq.heappop(queue)
    for v, w in graph[cur_node]:
        if visited[v]:
            continue
        if distance[cur_node] + w < distance[v]:
            distance[v] = distance[cur_node] + w
            heapq.heappush(queue, (distance[v], v))
    visited[cur_node] = True

for i in range(1, V+1):
    if distance[i] == float('inf'):
        print("INF")
    else:
        print(distance[i])
