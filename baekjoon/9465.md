### Question
**문제**
상근이의 여동생 상냥이는 문방구에서 스티커 2n개를 구매했다. 스티커는 그림 (a)와 같이 2행 n열로 배치되어 있다. 상냥이는 스티커를 이용해 책상을 꾸미려고 한다.

상냥이가 구매한 스티커의 품질은 매우 좋지 않다. 스티커 한 장을 떼면, 그 스티커와 변을 공유하는 스티커는 모두 찢어져서 사용할 수 없게 된다. 즉, 뗀 스티커의 왼쪽, 오른쪽, 위, 아래에 있는 스티커는 사용할 수 없게 된다.

![](https://www.acmicpc.net/upload/images/sticker.png)

모든 스티커를 붙일 수 없게된 상냥이는 각 스티커에 점수를 매기고, 점수의 합이 최대가 되게 스티커를 떼어내려고 한다. 먼저, 그림 (b)와 같이 각 스티커에 점수를 매겼다. 상냥이가 뗄 수 있는 스티커의 점수의 최댓값을 구하는 프로그램을 작성하시오. 즉, 2n개의 스티커 중에서 점수의 합이 최대가 되면서 서로 변을 공유 하지 않는 스티커 집합을 구해야 한다.

위의 그림의 경우에 점수가 50, 50, 100, 60인 스티커를 고르면, 점수는 260이 되고 이 것이 최대 점수이다. 가장 높은 점수를 가지는 두 스티커 (100과 70)은 변을 공유하기 때문에, 동시에 뗄 수 없다.

**입력**
첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스의 첫째 줄에는 n (1 ≤ n ≤ 100,000)이 주어진다. 다음 두 줄에는 n개의 정수가 주어지며, 각 정수는 그 위치에 해당하는 스티커의 점수이다. 연속하는 두 정수 사이에는 빈 칸이 하나 있다. 점수는 0보다 크거나 같고, 100보다 작거나 같은 정수이다. 

**출력**
각 테스트 케이스 마다, 2n개의 스티커 중에서 두 변을 공유하지 않는 스티커 점수의 최댓값을 출력한다.

### My Answer
기본적으로 어떤 1칸을 선택하면 해당 칸 주변 4칸 모두를 선택할 수 없다. 따라서 최적의 칸만 선택하는 전략이 필요했다.

1번째 아이디어: Greedy하게 항상 남은 우표 중 제일 좋은 우표만 고르면 될까?
→ 문제점: 같은 값을 갖는 우표 중 어떤 우표가 제일 최적일지 알기 어려움, 매번 최대값을 갖는 우표를 탐색해야 함

**[[Dynamic Programming|Dynamic Programming!]]**
2번째 아이디어: 특정 $N$번째 열에 이전 $N-1$열까지 최선의 선택을 한 결과를 더한다!
나는 총 3가지 경우가 있다고 생각하고 문제를 해결하였다.
(사실 이 중 1가지는 없어도 되더라…)

특정 `N`번째 열까지 선택할 수 있는 스티커 값들의 최댓값인 `DP[0][N]`을 구하자. 이때 스티커의 값들이 들어있는 배열을 `board[][]`라고 하겠다.
1. `DP[1][N-1]`: 가장 쉬운 케이스이다. 바로 직전 열에 대각선으로 위치한 스티커를 선택하는 경우이다.
2. `DP[0][N-2]`: 구하고자 하는 칸에서 옆으로 두 칸 건너 있는 스티커를 선택한 경우이다. 나는 이 값을 `DP[0][N]`을 구하는데 이용했는데, `board[0][N-2]`의 값을 선택하면 반드시 `board[1][N-1]`를 거쳐서 `board[0][N]`에 올 수 있기 때문에 `DP[1][N-1]`의 값이 반드시 `DP[0][N-2]` 보다 크다.
3. `DP[1][N-2]`: 처음에 직관적으로 찾기가 어려웠다. 테스트케이스의 입력을 보고 발견할 수 있었다. `board[1][N-2]`를 선택한다는 것은, `N-1`번째 열에서 아무것도 선택하지 않고 넘어가겠다고 하는 것과 동일하다.
따라서, `DP[0][N] = max(DP[1][N-1], DP[1][N-2]) + board[0][N]`으로 정의할 수 있고, `DP[1][N]`의 경우 또한 마찬가지로 정의할 수 있다.

### Code
```python
import sys

T = int(sys.stdin.readline().strip())
for _ in range(T):
    N = int(sys.stdin.readline().strip())
    board = [ list(map(int, sys.stdin.readline().strip().split())) for _ in range(2) ]
    
    dp = [[0]*(N+2) for _ in range(2)]
    for j in range(N):
        for i in range(2):
            dp[i][j+2] = max(dp[i][j], dp[1-i][j+1], dp[1-i][j]) + board[i][j]

    print(max(max(dp[0]), max(dp[1])))
```
이론적인 부분과 다른 점은, DP 테이블에서 `N`열에 대해 `N-1`과 `N-2`열의 값이 필요하므로 이를 예외처리 하여야 하는데, DP 테이블 자체를 `N+2`열로 구성하므로서 이러한 문제를 피했다. 
즉, `board[i][N]`에 해당하는 DP 테이블의 값은 `dp[i][N+2]`가 되는 것이다.

또한, 이 문제는 DP 테이블의 값을 구하는 순서도 중요하기 때문에, 한 개의 열에 대해서 모두 값을 구하고 다음 열로 넘어가는 방식을 구현했다.
`dp[i][j+2] = max(dp[1-i][j+1], dp[1-i][j]) + board[i][j]`
해당 부분은 `i==0`일 때는 `1`행의 DP 테이블에서 값을 비교하고, `i==1`일 때는 `0`행의 DP 테이블에서 값을 비교하게 함으로써, 불필요한 `if`문의 사용을 피하고자 했다.

코드 상 개선할 부분은,
1. DP 테이블 상 값을 구할 때 불필요한 값을 비교하는 것
2. 최종 최댓값을 구할 때 DP 테이블의 마지막 행만 비교하지 않은 것
이 정도로 요약할 수 있다.
