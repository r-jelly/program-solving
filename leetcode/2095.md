### Question
You are given the `head` of a linked list. **Delete** the **middle node**, and return _the_ `head` _of the modified linked list_.

The **middle node** of a linked list of size `n` is the `⌊n / 2⌋th` node from the **start** using **0-based indexing**, where `⌊x⌋` denotes the largest integer less than or equal to `x`.

- For `n` = `1`, `2`, `3`, `4`, and `5`, the middle nodes are `0`, `1`, `1`, `2`, and `2`, respectively.

**Example 1:**

![](https://assets.leetcode.com/uploads/2021/11/16/eg1drawio.png)
**Input:** head = [1,3,4,7,1,2,6]
**Output:** [1,3,4,1,2,6]
**Explanation:**
The above figure represents the given linked list. The indices of the nodes are written below.
Since n = 7, node 3 with value 7 is the middle node, which is marked in red.
We return the new list after removing this node. 

**Example 2:**

![](https://assets.leetcode.com/uploads/2021/11/16/eg2drawio.png)
**Input:** head = [1,2,3,4]
**Output:** [1,2,4]
**Explanation:**
The above figure represents the given linked list.
For n = 4, node 2 with value 3 is the middle node, which is marked in red.

**Example 3:**

![|300](https://assets.leetcode.com/uploads/2021/11/16/eg3drawio.png)
**Input:** head = [2,1]
**Output:** [2]
**Explanation:**
The above figure represents the given linked list.
For n = 2, node 1 with value 1 is the middle node, which is marked in red.
Node 0 with value 2 is the only node remaining after removing node 1.

**Constraints:**
- The number of nodes in the list is in the range `[1, 105]`.
- `1 <= Node.val <= 105`

### My Answer

1. 전체 리스트 길이를 구하기 위해 `head`부터 `None`까지 리스트를 순회하며 길이를 1씩 올린다.
2. 전체 길이에서 2로 나눈 몫을 구하고, 해당 횟수만큼 `head`에서 다음 노드로 이동한다.
3. 대상 노드의 앞 노드의 `next`를 대상 노드의 바로 뒷 노드로 연결해주어 대상 노드를 제거한다.
4. `head`를 그대로 `return`한다
→ 해결 성공 했으나, 시간복잡도와 공간복잡도 측면에서 많은 손해

#### Good Answer
길이를 찾고 그 길이의 절반만큼 다시 움직일 필요 없이, 두개를 동시에 작동한다.
1. 한 번에 두 개의 노드를 건너뛰는 포인터 `fast`와 한 번에 한 개의 노드를 이동하는 포인터 `slow`를 각각 정의한다.
2. 두 포인터 모두 시작 노드인 `head`에서 출발하며, `fast` 또는 `fast.next`가 `None`을 가리킬 때 까지 위에 정해진 규칙대로 이동한다.
3. 최종적으로 `slow`가 가리키는 노드의 이전 노드의 `next`를 `slow.next`로 일치시킨다.
→ 이렇게 하면 길이탐색과 제거를 동시에 수행할 수 있다!

### Code
```python
# Definition for singly-linked list.
class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
        
class Solution(object):
    def deleteMiddle(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        len_list = 1
        cur_node = head
        while cur_node.next is not None:
            cur_node = cur_node.next
            len_list += 1
        # O(N)

        if len_list==1:
            return None

        mid_idx = len_list//2
        prev_node = None
        cur_node = head
        for i in range(mid_idx):
            prev_node = cur_node
            cur_node = cur_node.next
        prev_node.next = cur_node.next
        return head
```
