### Question
**문제**
0과 1로 이루어진 이진 문자열 0101101은 0과 1의 개수의 차이가 1 이하이다. 뿐만 아니라, 첫 번째 문자를 포함하는 모든 부분 문자열 0, 01, 010, 0101, 01011, 010110, 0101101 모두 0과 1의 개수의 차이가 1 이하이다.

이와 같이, 이진 문자열 중에서 첫 번째 문자를 포함하는 모든 부분 문자열의 0과 1의 개수의 차이가 1이하인 문자열을 **균형잡힌 문자열**이라 부른다. 문자열 자체도 자신의 부분 문자열이다.

양의 정수 _n_ 이 주어질 때, 길이가 _n_ 인 이진 문자열 중에서 균형잡힌 문자열의 수를 구하는 프로그램을 작성하시오.

예를 들어, _n_ = 3인 경우에는 010, 011, 100, 101 네 개의 문자열이 균형잡힌 문자열이다.

**입력**
입력은 표준입력을 사용한다. 첫 번째 줄에 양의 정수 _n_ (1 ≤ _n_ ≤ 100,000)이 주어진다.

**출력**
출력은 표준출력을 사용한다. 길이가 _n_ 인 이진 문자열 중에서 균형잡힌 문자열의 개수를 16769023로 나눈 나머지 값을 한 줄에 출력한다.

### Solution
주어진 조건을 만족하는 길이 n인 모든 문자열의 개수를 구하는 문제.
첫 번째 문자를 포함하는 모든 부분 문자열의 0과 1의 개수 차이가 1 이하인 문자열 개수를 세면 된다.

결국 n-1 길이의 부분 문자열에 대해 길이 n인 문자열의 형태가 결정되고, n-2 길이 문자열에 대해 n-1 길이 문자열이 정해지고, 이것이 계속 반복되는 형태이다.

만약, 첫번째 문자가 `0`이라고 했을 때, 두번째 문자는 조건을 만족하기 위해 반드시 `1`이어야 한다. 세번째 문자는 `0` 또는 `1` 모두 들어가도 조건을 위배하지 않는다. 그러나 네번째 문자는 반드시 세번째 문자와는 달라야 한다. 위 규칙은 첫번째 문자가 `1`이어도 성립하게 된다.
즉, 경우의 수를 따졌을 때, `2*1*2*1*...`이 반복되는 형태이다. 따라서, 이를 일반화하면, 길이 `N`인 경우 모든 균형잡힌 문자열의 수는, $2^{\lfloor(N+1)/2\rfloor}$가 된다.

### Code
```python
N = int(input())
print(2**((N+1)//2) % 16769023)
```
