### Question
**문제**
정수 A를 B로 바꾸려고 한다. 가능한 연산은 다음과 같은 두 가지이다.

- 2를 곱한다.
- 1을 수의 가장 오른쪽에 추가한다. 

A를 B로 바꾸는데 필요한 연산의 최솟값을 구해보자.

**입력**
첫째 줄에 A, B (1 ≤ A < B ≤ 109)가 주어진다.

**출력**
A를 B로 바꾸는데 필요한 연산의 최솟값에 1을 더한 값을 출력한다. 만들 수 없는 경우에는 -1을 출력한다.

### Solution
특정 숫자 A에서 연산 2개만을 사용해서 특정 숫자 B에 도달할 수 있는지 여부를 파악하는 문제.
즉, 특정 Node에서 갈 수 있는 경로가 2개인 그래프에서 최단 경로를 탐색하는 문제와 동일하다.
따라서, Queue를 사용한 BFS로 해당 문제를 해결할 수 있다.

특정 숫자 노드 `num`에 대해서, 다음 깊이에 해당하는 노드의 값은 항상 `num*2, num*10+1`이다. 이때, 다음 노드의 값과 구하고자 하는 값 `B`에 따라서 가능한 동작은 다음 3가지와 같다.
1. `B`와 일치: 해당 노드까지의 깊이를 return
2. `B`보다 큼: 아무 동작을 하지 않고 넘어감
3. `B`보다 작음: Queue에 `(다음 노드의 값, 현재 깊이 + 1)`을 추가
이때, Queue가 모두 빈 공간일때 까지 경로에 도달하지 못한다면, `-1`을 return 하는 것으로 조건을 만족할 수 있다.

#### Other Solution
`A`에서 시작하는 것이 아니라, 반대로 `B`에서 시작하여 `A`로 도달할 수 있는지를 확인한다.
1. `B`의 마지막 자리수가 1인 경우: 마지막 1을 제거한다.
2. `B`가 2로 나누어떨어질 경우: 2로 나눈다.
위 두 가지 조건을 모두 만족하지 못한다면, `A`로 도달할 수 없다고 판단할 수 있다.

### Code
```python
from collections import deque

def solution(A: int, B: int):
    queue = deque([(A, 1)])
    while queue:
        cur_num, depth = queue.popleft()
        for next_num in [cur_num*2, cur_num*10+1]:
            if next_num == B:
                return depth+1
            elif next_num > B:
                continue

            queue.append((next_num, depth+1))
    return -1

A, B = list(map(int, input().split()))
print(solution(A, B))
```
