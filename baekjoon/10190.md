### Question
**문제**
There are many acronyms that have the same letters with different meanings. For example, ISS could mean International Space Station, In School Suspension, Interstate Sporadic Squabbles, but it could not be Institutional Saliva Tester (IST, not ISS) nor could it be Intermural Sports Situational Comedies (ISSC not ISS).

Determine whether or not phrases fit the acronym, with the correct number of words and beginning letters. All words will begin with capital letters.

**입력**
The first line contains the number of data sets (maximum of 10). Each data set contains the acronym and the number of possibilities (maximum of 10) on one line, followed by each possibility on a separate line.

**출력**
Show the acronym on one line followed by the phrases that match that acronym each on one line.

### Solution
각 단어의 앞글자만 따서 만든 새로운 단어를 두문자어(Acronym)이라고 한다.
주어진 두문자어에 대해서 입력된 문장의 두문자어와 일치하는지를 판단하는 문제이다.

두문자어 `acronym`을 입력받고 문장을 입력받았을 때, 문장을 단어 별로 나눠서 List에 저장한다.
그 후, 단어의 맨 앞 인덱스의 글자들만 따와서 새로운 단어를 만들고, 그 단어를 `acronym`과 일치하는지를 비교하는 방식으로 해결하였다.

### Code
```python
import sys
input = sys.stdin.readline

if __name__ == "__main__":
    N = int(input())
    for _ in range(N):
        acronym, M = input().split()
        print(acronym)

        for _ in range(int(M)):
            words = input().split()
            cur_acronym = ''.join([word[0] for word in words])
            if cur_acronym == acronym:
                print(' '.join(words))
```
